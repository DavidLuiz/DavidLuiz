## 💼 Lo que hago

- Desarrollo de sistemas web a medida (gestión documental, RRHH, control de recursos, portales institucionales)
- Arquitecturas backend en PHP con patrones MVC personalizados y Laravel
- APIs y backends con Node.js / NestJS
- Interfaces modernas y responsivas con React, Next.js, Vue y Angular
- Apps móviles multiplataforma con Flutter
- Apps de escritorio nativas con Tauri (Rust)

<br>

## 🛠️ Proyectos propios

- **DavCode** — Framework MVC propio en PHP, creado desde cero para desarrollo rápido de sistemas a medida.
- **DavServer** — Servidor local de escritorio construido con Tauri (Rust) + React + TypeScript.

<br>

## 🧭 Cómo trabajo

- Comunicación directa y constante con el cliente durante todo el proyecto
- Entregas incrementales: avances visibles y funcionales, no solo al final
- Código ordenado y mantenible, pensado para crecer sin reescribirse
- Diseño de UI en Figma antes de programar, cuando el proyecto lo requiere
- Documentación clara de cada sistema entregado
